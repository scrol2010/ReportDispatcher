# АвтоГРАФ 7 · Диспетчер отчётов

Программа для **массового формирования отчётов из АвтоГРАФ 7** — по многим машинам, сменам и дням за один раз, без ручного прокликивания в модуле «Отчёты».

АвтоГРАФ запускается в фоне и не мешает работе, готовые отчёты складываются по папкам.

## ⬇️ Скачать

**[Скачать последнюю версию](https://github.com/scrol2010/ReportDispatcher/releases/latest)** → внизу страницы, в разделе **Assets**, файл `ReportDispatcher_Setup.exe`.

## Возможности

- Формирование отчётов сразу по списку ТС, за период, **по сменам** (в том числе ночным, через полночь)
- Ваши собственные шаблоны отчётов (.frx) и стандартные отчёты АвтоГРАФа
- Карты маршрута в отчётах (включаются галочкой)
- Сохранение в **PDF, Excel, Word** или формат FastReport
- Раскладка по папкам по месяцам, в имени файла — госномер и название отчёта
- Наборы машин, шаблоны смен, календарь выходных
- Очередь заданий, архив с повтором, журнал работы
- Автоматические обновления

## Что нужно

- Windows 10 / 11 (64-бит)
- Установленный **АвтоГРАФ 7** (проверено на версии 2025.1.2)
- Данные по машинам должны быть загружены в АвтоГРАФ за нужный период

.NET и всё остальное уже встроено в установщик, отдельно ставить ничего не нужно.

## Установка

1. Скачайте `ReportDispatcher_Setup.exe` (ссылка выше).
2. Запустите и разрешите изменения (нужны права администратора).
   Если Windows покажет «Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**.
3. Установщик сам найдёт папку АвтоГРАФа (при необходимости укажите вручную) и спросит, куда установить программу.
4. На рабочем столе появится ярлык **«Диспетчер отчётов»**.

АвтоГРАФ перед установкой лучше закрыть. Дальше его запускает сам Диспетчер, закрывать или открывать АвтоГРАФ вручную не нужно.

## Пробный период и активация

После установки программа работает **14 дней** бесплатно. Для дальнейшей работы нужен ключ:

1. В программе нажмите **«Активировать»** (внизу окна или в Параметрах).
2. Отправьте автору **код компьютера** — кнопка «Отправить письмом» сама подготовит письмо.
3. Вставьте полученный ключ и нажмите «Активировать».

Ключ привязан к компьютеру.

## Обновления

Программа сама проверяет новые версии. В **Параметрах** можно выбрать: спрашивать перед обновлением, обновляться автоматически или не проверять. Настройки и ключ при обновлении сохраняются.
